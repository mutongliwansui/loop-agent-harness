# 🖥️ Web UI（浏览器图形界面）

> [⬅ 返回 README](../../../README.md)

`--serve` 模式在 REST API 之外同端口托管浏览器界面（Vue 3 + Vite 构建链，产物输出到 `webui/dist/`，由 `node:http` 静态层直接服务）：**打开网址即得聊天 + 全量运维管理台**，全部复用既有 REST 端点，API 行为零变化。

### 启动

```bash
npm run build:webui   # 首次或改动前端后构建（产物输出 webui/dist/，不入库，克隆后需构建一次）
npm run serve
# 或
npx tsx src/index.ts --serve
```

浏览器打开 `http://127.0.0.1:3000/` 即可使用。

```
HTTP API 服务已启动
  地址:    http://127.0.0.1:3000
  鉴权:    仅本机（未配置 api.token）
  端点:    /health · /status · /sessions · /uploads · /config · /tools · /models · /mcp · /skills · /memory
  提示:    Ctrl+C 退出；配置变更需重启生效
```

> 若 `webui/dist` 尚未构建（该产物不入库，克隆后默认不存在），静态层自动跳过，纯 API 服务不受影响；执行 `npm run build:webui` 构建即可。

### 鉴权（token 门）

与 REST API 完全同策略：静态页面本身不鉴权，页面内所有 API 调用走 Bearer。

- **未配置 token（默认）** → 本机访问零感，打开即用；
- **配置 token 后**（`/config set api.token xxx`，重启生效）→ 首次访问弹出 token 输入框，校验通过后记忆在浏览器 `localStorage`；token 失效（401）自动清空并重新弹出；
- 远程（局域网）访问时服务端需 `api.host` 绑定 `0.0.0.0` 且配置 `api.token`，浏览器端输入同一 token 即可。

### 开发者中心（API 接口文档）

`#/dev` 是面向二次开发者的入口（需求 20261104-002），用 tabs 组织多个模块，**第一个模块就是 API 接口文档**，并为后续开发者向模块（Webhook、SDK 示例等）留出插槽。

- **端点全集靠运行时反射，不靠手写清单**：`GET /dev/api-docs` 直接遍历 `src/api/router.ts` 的 `createRoutes()`，因此新增端点会自动出现在页面上，不可能漏登；中文说明/参数/示例来自代码内元数据 `src/api/api-docs.ts`，以 `METHOD /path` 为键。
- **漂移可观测，不静默**：元数据缺口的端点会以 `documented: false` 返回、前端标「说明待补」并计入 `stats.undocumented`；单测同时断言「路由全集 ↔ 元数据键集」双向一致（缺失报错、遗留幽灵键也报错），改路由忘补文档会直接失败 CI。
- **三个模块**：① API 接口文档（分组列表 + 搜索 + 方法筛选 + 展开看参数表/请求体/响应/curl）；② 鉴权与通用约定（token 三态与启动校验、错误码统一体、语义约定、当前鉴权状态位——**只显示模式不显示令牌明文**）；③ SSE 事件（帧格式、19 项事件表并区分「Agent 透传」与「API 合成」、`fetch` 流式接入片段）。
- **可深链**：模块状态写在 hash query（`#/dev?tab=sse`），刷新与分享都能还原；非法值回落到第一个模块。
- **零新增依赖**：不引入 swagger-ui / OpenAPI 运行时，前端只有一个纯函数模块（`webui/src/api-docs-ui.ts`，在 Node 下可直测）与一个视图文件。

### 文件预览区终端

文件预览区顶部是一条标签行：`📄 文件名` 与若干终端页签（`● PowerShell`、`● 命令提示符`）并列，右侧 `＋` 新建终端——终端是预览区的**一等公民**，不是浮层，也不需要左右分屏。终端页签左侧圆点即会话状态：绿色运行中、灰色已退出、红色异常，执行中替换为旋转指示。

- **shell 由运行时探测决定**：启动时检查 `pwsh.exe`（PowerShell 7）→ `powershell.exe`（Windows PowerShell 5.1）→ `cmd.exe`（POSIX 为 `$SHELL` / `bash` / `zsh`），只列出真实存在的；`pwsh.exe` 未安装时不会出现在下拉里（不会出现「点了报错」的假选项）。工作目录固定为当前会话的工作空间，工具条可点击复制路径。
- **通道**：`浏览器 (xterm.js) ⇄ WebSocket ⇄ 服务端 ⇄ 伪终端 PTY (ConPTY)`，滚动缓冲、光标、`Ctrl+C`、`↑` 历史、全屏 TUI 程序（如 `npm run build` 进度条）都按真实终端行为工作；窗口缩放与分割条拖拽后自动重算行列（`resize` 消息有 120ms 防抖）。
- **六态齐备**：未启动（居中 CTA + shell 卡片）/ 运行中（底部状态条：`● 已连接 · 96×27 · UTF-8 · PID · cwd`）/ 执行中（页签转圈 + 右下浮条「正在执行 xx · Ctrl+C」）/ 已退出（覆盖层显示退出码与运行时长，**输出保留可滚动**，可一键重启）/ 断连（顶部黄色横幅「正在重连…(2/5)」，指数退避 1s→2s→4s→8s）/ 缺 PTY（给出实际查找目录，并按部署形态给对应补救：开发环境 `npm i`，SEA 则把 `node_modules/@lydell` 放到 exe 同目录）。非存活态的状态条不会谎报「已连接」，清屏/复制按需置灰。
- **中文不乱码**：不注入 `chcp 65001`——ConPTY 内部走 UTF-16，服务端拿到的已是 UTF-8，`echo 中文测试✓` 回显正确；注入反而会污染既有输出并破坏依赖 OEM 代码页的工具。字体带中文回退（`Microsoft YaHei UI`）。
- **断连不丢画面**：每会话保留最近 256KB 输出环形缓冲，重连后先回放再续流；WS 断开后 PTY 保留 60s 宽限期供重连，超时才回收（Windows 用 `taskkill /T /F /PID` 清进程树，连 `conhost.exe` 一起收）。
- **关页签即释放**：点页签 `✕` 会立即通知服务端 kill PTY 并释放并发名额（与「网络闪断保留 60s 供重连」是两回事）；页面刷新/关闭走 `pagehide` 同样主动释放，最多 60s 兜底回收。因此反复开关终端不会出现「界面上没有终端却提示已达上限」。

**默认关闭，须显式开启**：终端等于「当前用户权限下的任意命令执行」，因此 `webui.terminal` 默认 `false`，未开启时 WS 握手直接 403（前端显示配置提示，不静默失败）。

```bash
# 开启终端（重启服务生效）
npm run cli -- /config set webui.terminal true

# 可选：拒绝名单（服务端生效，命中即拒绝并审计）、并发上限、空闲回收
npm run cli -- /config set webui.terminalDeny '["shutdown","format"]'
npm run cli -- /config set webui.terminalMax 4
npm run cli -- /config set webui.terminalIdleMs 1800000
```

安全约束：① 默认关闭；② 未配 `api.token` 时仅回环地址可用，非回环绑定且无 token 一律拒绝；③ WS 握手的 token 走 `Sec-WebSocket-Protocol` 子协议（浏览器 WebSocket 无法自定义头，query 传 token 会进访问日志）；④ `Origin` 白名单校验，防 CSRF 式跨站连接；⑤ 每次回车提交的命令写入会话日志可回溯；⑥ 前端危险命令（`del /s`、`rmdir /s`、`format`、`shutdown`）确认框只防手滑，**真正的边界在服务端拒绝名单与鉴权**。

依赖说明：前端 `@xterm/xterm` + `@xterm/addon-fit`；服务端 `ws` + `@lydell/node-pty`（**免编译**预编译版，避免 node-pty 官方包的 node-gyp / Python / VS Build Tools 链路）。未安装 `@lydell/node-pty` 时服务照常启动，终端降级为「交互式终端不可用」，提示文案由服务端 `GET /terminal/info` 的 `ptyHint` 给出——包含**实际查找过的目录**，并区分「开发环境 `npm i`」与「SEA 单文件部署需把 `node_modules/@lydell` 放在 exe 同目录随 exe 分发（`npm run build:sea` 已自动拷贝）」，避免用户对着 `npm i` 无从下手。

### 对话内上传

聊天输入框 📎 按钮打开上传面板：文件选择框（可多选）→ 逐文件以二进制直传 `POST /uploads/raw`（浏览器拿不到本地完整路径，故新增该端点；CLI 的 `/upload` 路径模式不受影响）→ 上传成功在输入框上方显示上下文 chip（文件名 + 大小），随下一条消息注入 Agent 上下文。chip ✕ 仅前端移除不再注入；「管理列表」可查看/清空已上传文件（动词即确认）。

**Ctrl+V 粘贴**：在输入框内直接 `Ctrl+V` 即可贴入截图（`Win+Shift+S` / QQ / 微信截图）或资源管理器里 `Ctrl+C` 复制的文件——两者浏览器都落在 `paste.clipboardData.files`，走同一条上传链路，不必先存盘再点 📎。Chrome 给截图用的默认名 `image.png` 会被改名为 `paste.png` / `paste-2.png`（服务端落盘名再带 `YYYYMMDD-HHmmss-` 前缀；前端不再自带时间戳，否则同秒多张前缀一致、被 chip 省略号截断后无法区分），普通文件一律保留原名。图片 chip 显示 24×24 本地缩略图，删除 / 发送成功 / 清空 / 离开页面四处释放 blob URL，发送失败则原样恢复（不提前释放，缩略图不会变碎图）。单次上限 6 个、按粘贴顺序串行上传、生成回复期间拦截。图片超过 `vision.maxImageBytes` 或视觉链路未启用时 chip 上出现 ⚠ 角标（悬停显示具体原因），不静默假装可读。纯文本粘贴完全走浏览器默认行为，不拦截、不提示。

### 对话流路径点击预览

工具调用卡片中的路径参数渲染为可点 chip（20261028-006，承接优化建议 20261028-003）：`fileRead` / `fileWrite` / `editFile` 的 `path`、`grep` 的 `path`（目录）、`commandRun` 的 `cwd`（目录）、视觉四件套（`describe_image` / `ask_image` / `ocr_image` / `extract_json`）的 `image`。点击文件 chip 自动展开文件面板并打开预览（复用 `FilesView.openFile` 既有渲染链路：md/html/svg/csv/xlsx/docx/pdf/图片/pptx/文本）；点击目录 chip 面板定位该目录；组卡（如「读取文件 ×3」）展开后逐次明细行中的路径同样可点。http(s) 链接、`data:` URI、缺失参数、工作空间之外的绝对路径不渲染为链接（悬停 title 注明原因），避免必然失败的点击。

uploads 图片（视觉工具落点 `~/.loop-agent/uploads/{sessionId}/`，工作空间之外 `/fs/*` 不可达）通过新增受控只读端点 `GET /uploads/view?path=&disp=file|raw` 预览：只读、词法防穿越（`resolveInWs`）+ 符号链接防逃逸（realpath）双校验，越界一律 403；`disp=file` 响应与 `/fs/file` 同构（512KB 截断、二进制拒绝），`disp=raw` 原始字节直显（Content-Type 按扩展名，上限 100MB）。历史会话回放同样生效（路径取自已持久化的 args）；文件不存在时预览区显示错误态并 toast 提示，不阻塞界面。

### 多标签页同步与后台完成提醒

同一浏览器打开多个标签页时，运行态自动互相同步（Task-20261021-002-07）：A 页发起/完成的运行，B 页 ≤1 秒出现运行点/未读点并刷新侧栏；A 页删除会话，B 页同步移除；A 页查看过的会话，B 页未读红点一并清除。通道为 `BroadcastChannel('loop-agent')`，旧浏览器自动降级 localStorage；广播只传派生状态（运行开始/结束/已读/删除），消息内容始终以服务端为准。

后台完成提醒在输入区 🔔 面板配置，两项独立开关且持久化：**系统通知**（仅窗口切走时弹，同会话通知互替防刷屏，点击通知回跳会话；权限仅在勾选时请求，浏览器拒绝后可去浏览器设置恢复）与**提示音**（WebAudio 合成双音，无需授权）。前台完成保持页内 toast 不变。通过局域网 IP + http 访问时浏览器不提供系统通知，🔔 面板会显示降级说明，提示音与页内提醒不受影响。

### 后台任务卡片（需求 20261104-005）

`commandRun` 传 `background:true` 后，工具卡片的结果区自动切换为后台任务卡片：头部展示命令全文与停止按钮（二次确认），摘要行展示状态 pill、耗时、退出码与日志大小；日志默认收起，展开拉取最后 20 行 / 2KB。运行中每 2s 轮询、页面隐藏降频 15s，终止态停止轮询；服务重启或日志按保留策略清理后卡片转「记录已清理」dim 态，不报错。数据来源为 `GET /background/:id`、`GET /background/:id/logs?tail=1` 与 `POST /background/:id/stop`。

后台任务结束时注入的完成通知（需求 20261104-004）在对话流中渲染为系统通知卡片（需求 20261105-001）：状态 pill（已完成/失败/已停止）+ 命令 + 耗时 + 默认折叠的日志尾部，不再是用户气泡原文；通知文本在注入前已剥离 ANSI 转义并收敛 `\r` 覆写，历史含 ANSI 的旧通知由前端解析层兜底清理。通知只用于展示与投递当轮，不作为普通历史消息进入后续请求的提示前缀（旧版遗留通知在恢复历史时同样被排除）。

### 跨工作空间会话

侧栏会话按工作空间分组展示（`GET /workspaces`）：来自其他空间的会话与当前空间**完全同权**——可直接打开续聊、与当前空间的运行并行、正常删除；空间的「当前」标记仅表示最近使用，不构成任何发送限制。跨空间运行互不影响，409 busy 只会在**同一会话**并发发消息时出现。

### 富内容渲染（公式与图表）

Markdown 正文（对话回答与文件 md/doc 预览共用渲染管线，`marked` + `DOMPurify` 消毒）支持：

- **数学公式**：`$E=mc^2$` 内联与 `$$..$$` 块级，KaTeX 排版（mermaid 图内 `$$..$$` 公式 v12 内置支持，仅流程图/时序图）；语法错误以红色片段原位提示，不阻断整段渲染。
- **Mermaid 图表**：mermaid 代码块渲染为 SVG，容器工具栏提供放大/缩小/适应宽度/全屏与滚轮缩放、拖拽平移，并按源码首个关键字标出图类型（流程图 / 时序图 / 类图…）；解析失败标红保留源码。
- **ECharts 图表**：echarts 代码块（纯 JSON option，声明式无脚本执行面）渲染为可交互 SVG 图表，容器交互与 Mermaid 一致，并按 `series[].type` 标出系列形态（柱状 / 折线 / 饼图…）；JSON 非法标红保留源码。
- **容器外观**：统一为「图标 + 类型名（图表 / 图示）+ 副标题」的标题栏 + 柔和边框卡片，按钮为图标式工具组（悬停显示名称），缩放读数可点击复位，可平移时右下角给出操作提示。
- **流式增量渲染**：正文按「稳定块 + 可变尾部」切分渲染，代码围栏**闭合即出图**，无需等整条回答输出完毕；已渲染的图表在后续输出过程中不被重渲销毁，缩放/全屏状态保持。围栏已开头未闭合时显示「正在生成图表…」占位（含已生成字符数），不再逐字刷屏裸源码；停止/失败后回退为可复制的代码块。
- **预览 ⇄ 源代码**：图表工具栏最右侧 `</>` 按钮切到源码态（等宽字体、可复制），切回预览不重建图表实例；源码态下缩放/全屏按钮置灰。
- 公式与图表均按需动态加载、明暗主题自适应（切换主题后已渲染图表自动重渲）；KaTeX 字体本地打包，离线可用。

### 滚动跟随与「回到最新」

流式输出期间视口默认贴住尾部（跟随最新内容）。这条跟随是可解除的，便于中途回读：

- **上滑即解绑**：滚轮、触摸滑动、拖动滚动条、聚焦消息区后按 `PageUp/PageDown/Home/End/ArrowUp/ArrowDown` 都会解除跟随，视口停在当前位置，后续增量不再把视口拽回底部（长回答、多轮工具调用期间可随时回看中间的调用参数与思考）。
- **滚回底部自动恢复**：手动滚回距底 24px 以内即重新吸附，恢复贴底跟随。
- **回到最新按钮**：解绑时消息区右下角出现悬浮下箭头按钮，点击平滑回到底部并恢复跟随；解绑期间若有新内容到达，按钮右上角显示品牌色圆点提示（不计数——流式是单条消息在增长，条数无意义）。
- **强制回底的场景**：自己发送消息、切换会话、新建会话时无论当前是否解绑都回到最新；而「本轮生成结束」在解绑状态下不抢回视口，只点亮圆点。
- **阅读位置稳定**：解绑期间的高亮与图表渲染（改变块高度）由浏览器滚动锚定校正，已读内容不漂移。

### 安全细节

- 静态层防路径穿越（`..%2f` 等 → 403）；`/assets/*` immutable 缓存一年，`index.html` 不缓存（升级即生效）。
- Markdown 渲染经 `marked` + `DOMPurify` 消毒，防模型输出注入脚本。
- API 错误以 toast 显示后端 `error.message`；409 busy、413 超限（单文件 100MB）等均有对应文案。
