## 一、任务目标需求

### 1.1 背景（痛点）

用户反馈「对话界面后台任务列表」展示不佳。取证对象为输入坞上方的常驻指示器 `webui/src/components/BackgroundDock.vue`（需求 20261112-006 统一了命令任务与后台子 Agent 任务）。

| 编号 | 现状（代码核对） | 症状 |
| --- | --- | --- |
| ① | `.sad-list` 无 `max-height`，展开后整块按内容高度撑开 | 任务一多（原型取 12 个：5 运行中 + 7 已结束）整块把输入坞顶出视口，用户既看不见输入框也够不到「停止」 |
| ② | 单一列表按 `jobsOf` 返回顺序平铺，终态任务与运行中混排 | 越跑越难找「还在跑的有哪些」 |
| ③ | `+N` 溢出汇总与 chips 同处 `overflow:hidden` 容器末尾 | 宽度一紧整条被裁掉，用户看不出「还有几个没显示」 |
| ④ | 任务 ID 与标题在同一行抢横向空间，状态词与停止按钮挤在行尾，失败行无错误原因 | 长 ID 把标题挤成省略号且无复制入口；「失败」二字看不到为什么 |
| ⑤ | ≤720px 时 chips、聚合耗时、chevron 全挤一行 | 最关键的「N 运行中」被挤出可视区 |

### 1.2 现状梳理

| 所需能力 | 框架现状 | 结论 |
| --- | --- | --- |
| 任务数据源 | `jobsOf(sessionId)` → `GET /sessions/:id/jobs` 2s 轮询快照，`JobTaskVM extends SubAgentTaskVM` | ✅ 字段齐全（`status`/`kind`/`canStop`/`startedAt`/`elapsedMs`/`iterations`/`error`），后端零改动 |
| 运行中／终态判定 | `status: 'running' \| 'done' \| 'failed' \| 'aborted' \| 'interrupted'` | ✅ 可直接分组，无需新字段 |
| 纯展示逻辑单测 | `webui/src/subagent-dock.ts` 不依赖 Vue，Node vitest 直测 | ✅ 新增逻辑全部放这里 |
| 展开区限高 | 组件 `<style scoped>`，与全局 `style.css` 令牌同源 | ✅ 纯 CSS 可解 |
| 深色主题 | 全部走 `--panel` / `--line` / `--brand` 等既有令牌 | ✅ 无需新增令牌 |

### 1.3 任务目标

1. **展开区限高 + 内部滚动**：`min(42vh, 320px)`（≤720px 降 240px），`overscroll-behavior:contain`，任务再多也不改变输入区位置。
2. **分两组**：运行中在上（组头常驻 `sticky`，行内序号与收起态 chips 一一对应）、已结束在下（组头可折叠、默认收起并带计数）。
3. **`+N` 恒定可见**：移出裁切容器（`flex:none`）；chips 容器加右端渐隐遮罩，不再硬切半截 chip。
4. **行内重排**：主行 = 状态点 + 类型徽标 + 两行截断标题；副行 = 耗时 / 轮次 / 任务 ID（缩略 9 字符 + 复制图标，`title` 给全 ID）；状态词与停止按钮收进右侧操作列；失败行附一行错误摘要。
5. **窄屏收敛**：保留图标 / 标题 / 计数 / 聚合耗时 / chevron，chips 与 `+N` 整条隐藏。

### 1.4 设计约束

- **后端零改动**：沿用 `GET /sessions/:id/jobs` 快照与 2s 轮询，不改 `JobTaskVM` 字段结构。
- **纯展示逻辑必须可 Node 直测**：新增的格式化/分组/截断规则全部进 `subagent-dock.ts`，组件只做布局与交互。
- **不引入新颜色**：只用 `--panel` / `--line` / `--brand` / `--ok` / `--danger` / `--muted` / `--code-bg` 等既有令牌；颜色只作用于状态点与状态词，不做整行染色。
- **不做假进度**：后端没有总步数，禁止百分比进度条；进行中只表达「仍在跑」（顶部呼吸线 + 状态点呼吸）。
- **不擅自重启用户服务**（当前 `loop-agent.exe --serve` 占 3000 端口）。

## 二、方案设计

### 2.1 总体思路

```
        ┌── 收起态（.sad-head）──────────────────────────────────────┐
        │ [图标] 后台任务  3 运行中 │ #1 42s │ #2 8s │ #3 1m02s │ +5 │ 共 1m02s ▾│
        │                          └─ chips（可裁切，右端渐隐）─┘  └ 容器外 ┘  │
        └────────────────────────────────────────────────────────────┘
                                   │ 点击展开
                                   ▼
        ┌── 展开态（.sad-list，max-height: min(42vh,320px)，内部滚动）──┐
        │ ▍运行中 2          ← 组头 sticky                                │
        │ ● [命令] npm run build                                          │
        │   ⏱ 1m02s  3 轮  ⧉ cmd_33aa9…                    进行中 停止   │
        │ ● [子任务] 全量比对 README 中英                                  │
        │   ⏱ 42s  1 轮  ⧉ sub_4d2b8…                        进行中      │
        │ ▍已结束 7  点此展开   ← 组头可折叠，默认收起                     │
        │   ● [命令] 失败的那条                                            │
        │     ⏱ 5s  ⧉ cmd_91f...                    失败                  │
        │     ENOENT: no such file or directory   ← 错误摘要              │
        └────────────────────────────────────────────────────────────────┘
```

### 2.2 关键设计决策

**D1｜展开区限高 `min(42vh, 320px)`，窄屏降 240px。**
`42vh` 保证视口高时能看更多行；`320px` 兜住超高视口（不让指示器喧宾夺主）。被否决：固定 `320px`——小视口（如 600px 高）下 320px 占掉一半。

**D2｜分组口径集中在 `dockGroups()`，不在组件里写过滤。**
组件只用 `groups.running` / `groups.ended`，判定只在一处。`dockGroups` 用泛型 `<T extends SubAgentTaskVM>`，保留 `kind` / `canStop` 等 `JobTaskVM` 扩展字段不失真（单测已断言）。

**D3｜已结束组默认收起（`DOCK_DONE_OPEN_DEFAULT = false`）。**
默认态的首要任务是「看全还在跑的」。终态任务的时间线里已有结果卡片，这里的列表是补充。被否决：默认全部展开——12 个任务时首屏看到的仍是混排。

**D4｜`+N` 移出 `overflow:hidden` 容器。**
`.sad-chips` 负责裁切（`flex:1` + 遮罩渐隐），`.sad-more` 为 `.sad-head` 的直接子元素 `flex:none`。被否决：把 `+N` 放 chips 末尾靠 `flex-shrink:0`——容器仍会裁，只是裁不到它，语义不成立。

**D5｜任务 ID 缩略为「9 字符 + …」（`DOCK_ID_MAX = 11`）并做成复制按钮。**
阈值 11 的选择：`cmd_33aa90d7`（12 字符）在 92px 上不截断会挤掉「轮次」；11 以内原样显示（如 `cmd_1`），超过截前 9 加省略号。全 ID 进 `title`，点击复制并 toast。被否决：`title` + 文本 —— 无法复制，而 ID 的用处就是拿去 `commandStatus` / `commandLogs`。

**D6｜状态词进右侧操作列，而非行首。**
行首是「是什么任务」（类型 + 标题），行尾是「现在怎么样 + 能做什么」。被否决：状态词放标题前 —— 与类型徽标抢位，且终态词（完成/失败/已取消/已中断）长度不一，行首对齐会抖。

**D7｜失败行附一行错误摘要（`DOCK_ERROR_MAX = 60`，取首个非空行）。**
多行堆栈在列表里没有阅读价值，首行足够定位。完整错误在 `title` 里。

**D8｜后台子任务不提供停止入口。**
沿用 `canStop` 语义：命令任务可杀进程树，子 Agent 任务是 Agent 内部执行，停止语义不成立（本期不动）。

**D9｜窄屏（≤720px）整条隐藏 chips 与 `+N`，而不是折行。**
折行会让头部占两行，反而更挤。窄屏真正需要的是「有几个在跑 + 多久」，「#几」的序号价值低。≤480px 再隐藏单任务短名。

### 2.3 外部检索结论

| 来源 | 结论 | 对本任务的指导 |
| --- | --- | --- |
| MDN / CSS 规范 `overscroll-behavior` | `contain` 阻止滚动链传播，内层滚到底时不带动外层滚动 | 展开区内部滚动不会带动整页（`sad-list` 采用） |
| Chrome / Safari `-webkit-line-clamp` 现状 | 多行截断需 `display:-webkit-box` + `-webkit-box-orient:vertical`，`line-clamp` 标准属性尚未全量生效 | 标题两行截断、错误摘要一行截断均写成兼容组合（现状项目其他处已同用法） |
| `position:sticky` 在滚动容器内的行为 | sticky 相对最近的滚动祖先生效；祖先若有 `overflow:hidden` 会失效 | `.sad` 的 `overflow:hidden` 在 `.sad-list` 之外，组头 sticky 相对 `.sad-list` 生效（CDP 实测 `position:sticky` / `top:0` 已生效） |

## 三、任务详细设计

### 3.1 纯展示逻辑（`webui/src/subagent-dock.ts`）

| 导出 | 作用 |
| --- | --- |
| `DOCK_LIST_MAX_PX = 320` | 与组件 CSS `min(42vh, 320px)` 同口径 |
| `DOCK_DONE_OPEN_DEFAULT = false` | 已结束组默认收起 |
| `DOCK_ID_MAX = 11` | 任务 ID 缩略阈值 |
| `dockStatusLabel(status)` | running→进行中 / done→完成 / failed→失败 / aborted→已取消 / interrupted→已中断 |
| `dockKindLabel(kind)` | command→命令 / subagent→子任务 |
| `dockShortId(id, max)` | 不超阈值原样返回，超过截前 9 加 `…` |
| `dockGroups(tasks)` | `{running, ended}`，各自保持原顺序，泛型保留扩展字段 |

### 3.2 组件模板（`webui/src/components/BackgroundDock.vue`）

- 收起态头部：图标徽标 + 标题 + 计数胶囊 + `.sad-chips`（可裁切）+ `.sad-more`（容器外）+ 聚合耗时 + chevron。
- 展开态：`.sad-list` → 运行中组（`.sad-gh.static` 组头 + `.sad-row[data-s=running]`）→ 已结束组（`.sad-gh` 可点组头 + `v-if="doneOpen"` 行）。
- 行内：`.sad-dot` / `.sad-kind[data-k]` / `.sad-task`（两行截断）/ `.sad-meta`（耗时 svg + 轮次 + `.sad-id` 复制按钮）/ `.sad-err` / `.sad-act`（状态词 + 停止）。

### 3.3 样式要点（`<style scoped>`）

| 选择器 | 关键声明 |
| --- | --- |
| `.sad-list` | `max-height: min(42vh,320px)`、`overflow-y:auto`、`overscroll-behavior:contain` |
| `.sad-gh` | `position:sticky; top:0; z-index:1`，`.static` 时 `cursor:default` 且 hover 不换色 |
| `.sad-chips` | `flex:1; min-width:0; overflow:hidden` + 右端 16px 渐隐 `mask-image` |
| `.sad-more` | `flex:none`（容器外恒定可见） |
| `.sad-row[data-s]` | 状态点与状态词按 `running`/`done`/`failed`/`aborted,interrupted` 四类着色 |
| `@media (max-width:720px)` | `.sad-chips, .sad-more {display:none}`、`.sad-list{max-height:240px}`、标题三行 |
| `@media (prefers-reduced-motion:reduce)` | 呼吸动画全部关闭 |
