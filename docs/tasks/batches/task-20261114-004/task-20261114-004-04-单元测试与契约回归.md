## 一、任务目标需求

### 1.1 背景（痛点）

持久化注册中心的失效模式大多是**静默的**，不测就发现不了：

- 原子写没做对 → 只在「写的同时有读」或「进程崩溃」时才暴露，日常跑一次永远看不出。
- 坏档容错没做对 → 只在用户手改坏文件后启动才暴露，届时时整个进程起不来。
- 落盘失败没隔离 → 只在磁盘满/权限不足时暴露，届时挂载跟着一起失败。
- 跨实例还原没做对 → 只在重启后才暴露，而开发者天天热重载，根本不会重启。

core 侧则相反：删掉 `PluginRegistry` 后，`boundary.test.ts` 的「产物恰好 3 文件」「零外部 import」等断言会立刻告诉你有没有破坏契约。

### 1.2 现状梳理

| 所需能力 | 框架现状（链接） | 结论 |
|---|---|---|
| core 测试基线 | `core/tests/` 下 10 个测试文件（含 `boundary` / `diagnose` / `types` / `external-consumer`），当前全绿 | **回归基线** |
| 测试隔离约定 | 主工程 `src/user-home.ts` 读 `LOOP_AGENT_HOME`，vitest `setupFiles` 注入临时目录 | main 侧自行以 `mkdtempSync` 注入 `manifestFile`/`home`，不污染真实目录 |
| main 测试 | **不存在**（任务 02 只建目录） | **新增 3 个文件** |
| 边界断言范式 | `core/tests/boundary.test.ts` 逐行扫源码说明符，断言零三方依赖 / 零反向依赖 / 单副本 / 无 TLA | **照抄范式** |

### 1.3 任务目标

1. `main/tests/store.test.ts`：读写往返、原子写、坏档容错、结构校验、`lastError`。
2. `main/tests/registry.test.ts`：五个写操作均落盘、启停保留条目、排序、加载失败隔离、落盘失败隔离、跨实例还原、幂等卸载。
3. `main/tests/boundary.test.ts`：单副本、零 `src/` 反向依赖、`dependencies` 仅 core、`external` 已配。
4. core 侧回归：删净 `PluginRegistry` 后 `boundary` / `external-consumer` / `types` / `diagnose` 全绿。

### 1.4 设计约束

- 测试**不得写入真实 `~/.loop-agent`**：一律 `mkdtempSync` 生成临时目录，`afterEach` 删除。
- 测试**不得实际 `import()` 磁盘上的 ESM 模块**（慢且易碎）：用 `loadPlugin` 注入内存插件工厂；仅「加载失败」用例注入一个必抛的工厂。
- 时间敏感断言（mtime 变化）在 Windows 上毫秒精度可能相同 → 改用**文件内容比对**而非 mtime。
- main 单测必须能在**未 build** 时跑通（vitest 直接读 `src/`）。

## 二、方案设计

### 2.1 总体思路

```
main/tests/
├── store.test.ts       纯文件层：不碰 registry
│   ├─ 文件不存在 → 空清单
│   ├─ 写→读 往返一致
│   ├─ 覆盖写（目标已存在）
│   ├─ 坏 JSON → 空清单 + .bad 备份 + lastError
│   ├─ schemaVersion 不识别 → 同坏档
│   ├─ entries 非数组 → 同坏档
│   ├─ 条目字段非法 → 跳过该条
│   ├─ id 重复 → 保留首个
│   └─ 只读目录写失败 → {ok:false} + lastError
│
├── registry.test.ts    组合层：内存 loadPlugin
│   ├─ mount → 条目 + Fiber ACTIVE + 文件已写
│   ├─ 五写操作各触发落盘（内容比对）
│   ├─ disable 保留条目 / enable 重挂原位
│   ├─ reorder 顺序 + 未列出者尾部
│   ├─ mount 重复 id 抛 CONFLICT
│   ├─ enable/reorder 未知 id 抛 NOT_FOUND
│   ├─ unmount/disable 未知 id 幂等且不写盘
│   ├─ loadPlugin 抛错 → loadError 且其余 ACTIVE
│   ├─ 落盘失败 → 内存更新 + persistError + 不抛
│   ├─ 新实例 restore() 还原
│   └─ dispose 逆序 + 幂等
│
└── boundary.test.ts    静态层：扫源码 + 扫 package.json
    ├─ 源码说明符只允许相对 / node: / @loop-agent/core
    ├─ 零 import 主工程 src/
    ├─ dependencies 仅 @loop-agent/core
    ├─ tsup 配了 external
    └─ node_modules/@loop-agent/core 为链接（单副本）
```

### 2.2 关键设计决策

| 编号 | 决策 | 理由 | 被否决项 |
|---|---|---|---|
| **D20**（本任务新增） | 用 `loadPlugin` 注入内存插件，**不落真实 ESM 文件** | 真实 `import()` 需要写临时 `.mjs` + 走 Node 解析，慢（每个用例数十 ms 到数百 ms）且在 Windows 上可能被文件锁阻塞；注入工厂让单测保持纯内存 | 写临时 `.mjs` 再 `import()`（慢、易碎）；用 `data:` URI import（Node 支持但错误栈不可读） |
| **D21**（本任务新增） | 落盘断言用**文件内容比对**，不用 mtime | Windows 的 `fs` mtime 精度可能只有 1s/2s，连续两次写常拿到相同 mtime，断言会假通过 | 断言 mtime 变化（Windows 上不可靠） |
| **D22**（本任务新增） | 「原子写」用**并发读压测**验证：写大清单循环 N 次，同时另一路反复 `read()`，断言每次读要么解析成功、要么文件不存在，**绝不出现 JSON 解析错误** | 原子性的本质是「读方看不到半截」，直接测这个性质才有效 | 只测「写完能读回」（测不出非原子写的中间态） |

```ts
import { afterEach, beforeEach, describe, expect, it } from 'vitest';
import { mkdtempSync, rmSync, readFileSync, writeFileSync, mkdirSync, chmodSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { createPluginStore } from '../src/store.js';
import { MANIFEST_SCHEMA_VERSION, emptyManifest } from '../src/types.js';

let dir: string;
let file: string;

beforeEach(() => {
  dir = mkdtempSync(join(tmpdir(), 'loop-main-store-'));
  file = join(dir, 'plugins', 'registry.json');
});
afterEach(() => {
  rmSync(dir, { recursive: true, force: true });
});

describe('PluginStore：清单读写', () => {
  it('文件不存在时返回空清单', () => {
    const store = createPluginStore({ file });
    expect(store.read()).toEqual({ ...emptyManifest(), updatedAt: expect.any(String) });
    expect(store.lastError()).toBeUndefined();
  });

  it('写→读 往返一致', () => {
    const store = createPluginStore({ file });
    const manifest = {
      schemaVersion: MANIFEST_SCHEMA_VERSION,
      entries: [{ id: 'a', specifier: './a.js', enabled: true }],
      updatedAt: '2026-11-14T00:00:00.000Z',
    };
    expect(store.write(manifest)).toEqual({ ok: true });
    expect(store.read()).toEqual(manifest);
  });

  it('目标文件已存在时可覆盖写（Windows rename 语义）', () => {
    const store = createPluginStore({ file });
    store.write({ ...emptyManifest(), entries: [{ id: 'a', specifier: './a.js', enabled: true }] });
    const second = { ...emptyManifest(), entries: [{ id: 'b', specifier: './b.js', enabled: false }] };
    expect(store.write(second)).toEqual({ ok: true });
    expect(store.read().entries).toEqual(second.entries);
  });

  it('不留下 .tmp 残留文件', () => {
    const store = createPluginStore({ file });
    store.write(emptyManifest());
    expect(readdirSync(join(dir, 'plugins')).filter((n) => n.includes('.tmp.'))).toEqual([]);
  });
});

describe('PluginStore：坏档容错（D9）', () => {
  it('JSON 损坏时返回空清单并备份坏档', () => {
    mkdirSync(join(dir, 'plugins'), { recursive: true });
    writeFileSync(file, '{', 'utf8');
    const store = createPluginStore({ file });
    expect(store.read().entries).toEqual([]);
    expect(store.lastError()).toBeInstanceOf(Error);
    const backups = readdirSync(join(dir, 'plugins')).filter((n) => n.includes('.bad.'));
    expect(backups).toHaveLength(1);
    expect(readFileSync(join(dir, 'plugins', backups[0]), 'utf8')).toBe('{');
  });

  it('schemaVersion 不识别时降级为空清单并备份', () => {
    mkdirSync(join(dir, 'plugins'), { recursive: true });
    writeFileSync(file, JSON.stringify({ schemaVersion: 999, entries: [] }), 'utf8');
    const store = createPluginStore({ file });
    expect(store.read().entries).toEqual([]);
    expect(readdirSync(join(dir, 'plugins')).some((n) => n.includes('.bad.'))).toBe(true);
  });

  it('entries 非数组时降级为空清单并备份', () => {
    mkdirSync(join(dir, 'plugins'), { recursive: true });
    writeFileSync(file, JSON.stringify({ schemaVersion: 1, entries: 'oops' }), 'utf8');
    const store = createPluginStore({ file });
    expect(store.read().entries).toEqual([]);
    expect(readdirSync(join(dir, 'plugins')).some((n) => n.includes('.bad.'))).toBe(true);
  });

  it('条目字段非法时跳过该条，其余保留', () => {
    mkdirSync(join(dir, 'plugins'), { recursive: true });
    writeFileSync(
      file,
      JSON.stringify({
        schemaVersion: 1,
        entries: [
          { id: '', specifier: './x.js', enabled: true },
          { id: 'no-spec', enabled: true },
          { id: 'ok', specifier: './ok.js', enabled: true },
        ],
      }),
      'utf8',
    );
    const store = createPluginStore({ file });
    expect(store.read().entries.map((e) => e.id)).toEqual(['ok']);
  });

  it('id 重复时保留首个', () => {
    mkdirSync(join(dir, 'plugins'), { recursive: true });
    writeFileSync(
      file,
      JSON.stringify({
        schemaVersion: 1,
        entries: [
          { id: 'dup', specifier: './first.js', enabled: true },
          { id: 'dup', specifier: './second.js', enabled: false },
        ],
      }),
      'utf8',
    );
    const store = createPluginStore({ file });
    expect(store.read().entries).toEqual([{ id: 'dup', specifier: './first.js', enabled: true }]);
  });

  it('enabled 缺失时视为启用', () => {
    mkdirSync(join(dir, 'plugins'), { recursive: true });
    writeFileSync(file, JSON.stringify({ schemaVersion: 1, entries: [{ id: 'a', specifier: './a.js' }] }), 'utf8');
    expect(createPluginStore({ file }).read().entries[0].enabled).toBe(true);
  });
});

describe('PluginStore：原子写（D8 / D22）', () => {
  it('并发读永不见半截 JSON', async () => {
    const store = createPluginStore({ file });
    // 先写一份大清单，拉长单次写耗时
    const big = {
      ...emptyManifest(),
      entries: Array.from({ length: 400 }, (_, i) => ({ id: `p${i}`, specifier: `./p${i}.js`, enabled: true })),
    };
    store.write(big);

    let stop = false;
    const readErrors: string[] = [];
    const reader = (async () => {
      while (!stop) {
        try {
          // 直接读文件（绕过 store 的容错，才能暴露半截 JSON）
          JSON.parse(readFileSync(file, 'utf8'));
        } catch (e) {
          if ((e as NodeJS.ErrnoException).code !== 'ENOENT') readErrors.push(String(e));
        }
        await new Promise((r) => setImmediate(r));
      }
    })();

    for (let i = 0; i < 60; i++) store.write(big);
    stop = true;
    await reader;
    expect(readErrors).toEqual([]);
  });

  it('写失败时返回 ok:false 并记录 lastError', () => {
    // 目标父路径是个文件，无法建目录 → 必然失败
    const blocker = join(dir, 'blocked');
    writeFileSync(blocker, 'x', 'utf8');
    const store = createPluginStore({ file: join(blocker, 'registry.json') });
    const result = store.write(emptyManifest());
    expect(result.ok).toBe(false);
    expect(store.lastError()).toBeInstanceOf(Error);
  });
});
```

### 3.2 `main/tests/registry.test.ts`

```ts
import { afterEach, beforeEach, describe, expect, it } from 'vitest';
import { mkdtempSync, rmSync, readFileSync, writeFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { createHost, createRootContext, type Plugin } from '@loop-agent/core';
import { PersistentPluginRegistry } from '../src/registry.js';
import { createPluginStore } from '../src/store.js';

let dir: string;
let file: string;

/** 内存插件：apply 里挂一个 disposer，便于断言卸载顺序 */
const makePlugin = (order?: string[], name = 'p'): Plugin => ({
  name,
  apply: (c) => {
    c.effect(() => () => {
      order?.push(name);
    });
  },
});

/** 注入式加载器：specifier 形如 'mem:<name>' */
const loadPlugin = async (specifier: string, order?: string[]): Promise<Plugin> => {
  const name = specifier.replace('mem:', '');
  if (name === 'boom') throw new Error('load failed: boom');
  return makePlugin(order, name);
};

function makeRegistry(order?: string[], opts: { failWrite?: boolean } = {}) {
  const host = createHost();
  const context = createRootContext(host);
  const store = createPluginStore({ file: opts.failWrite ? join(dir, 'blocked', 'registry.json') : file });
  const registry = new PersistentPluginRegistry({
    context,
    host,
    store,
    loadPlugin: (s) => loadPlugin(s, order),
  });
  return { host, context, store, registry };
}

beforeEach(() => {
  dir = mkdtempSync(join(tmpdir(), 'loop-main-reg-'));
  file = join(dir, 'registry.json');
});
afterEach(() => {
  rmSync(dir, { recursive: true, force: true });
});

const readManifest = () => JSON.parse(readFileSync(file, 'utf8'));

describe('PersistentPluginRegistry：增删', () => {
  it('mount 后条目在、Fiber ACTIVE、文件已落盘', async () => {
    const { registry, host } = makeRegistry();
    const fiber = await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await host.settle();
    expect(fiber.state).toBe('ACTIVE');
    expect(registry.entries()).toEqual([{ id: 'a', specifier: 'mem:a', enabled: true }]);
    expect(readManifest().entries).toEqual([{ id: 'a', specifier: 'mem:a', enabled: true }]);
  });

  it('mount 重复 id 抛 PLUGIN_ID_CONFLICT', async () => {
    const { registry } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await expect(registry.mount({ id: 'a', specifier: 'mem:a2', enabled: true })).rejects.toThrow(/重复/);
  });

  it('unmount 卸载 Fiber 并删条目', async () => {
    const { registry } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await registry.unmount('a');
    expect(registry.entries()).toEqual([]);
    expect(registry.fiberOf('a')).toBeUndefined();
    expect(readManifest().entries).toEqual([]);
  });

  it('unmount 未知 id 幂等且不写盘', async () => {
    const { registry } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    const before = readFileSync(file, 'utf8');
    await registry.unmount('nope');
    expect(readFileSync(file, 'utf8')).toBe(before);
  });
});

describe('PersistentPluginRegistry：启停（D7）', () => {
  it('disable 保留条目、卸 Fiber、落盘 enabled=false', async () => {
    const { registry } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await registry.disable('a');
    expect(registry.entries()).toEqual([{ id: 'a', specifier: 'mem:a', enabled: false }]);
    expect(registry.fiberOf('a')).toBeUndefined();
    expect(readManifest().entries[0].enabled).toBe(false);
  });

  it('enable 重新挂载且条目位置不变', async () => {
    const { registry, host } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await registry.mount({ id: 'b', specifier: 'mem:b', enabled: true });
    await registry.disable('a');
    await registry.enable('a');
    await host.settle();
    expect(registry.entries().map((e) => e.id)).toEqual(['a', 'b']);
    expect(registry.fiberOf('a')?.state).toBe('ACTIVE');
    expect(readManifest().entries[0].enabled).toBe(true);
  });

  it('disable 已停用者幂等且不写盘', async () => {
    const { registry } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await registry.disable('a');
    const before = readFileSync(file, 'utf8');
    await registry.disable('a');
    expect(readFileSync(file, 'utf8')).toBe(before);
  });

  it('enable 未知 id 抛 PLUGIN_NOT_FOUND', async () => {
    const { registry } = makeRegistry();
    await expect(registry.enable('nope')).rejects.toThrow(/不存在/);
  });
});

describe('PersistentPluginRegistry：排序（D17）', () => {
  it('reorder 按入参顺序重排并落盘', async () => {
    const { registry } = makeRegistry();
    for (const id of ['a', 'b', 'c']) await registry.mount({ id, specifier: `mem:${id}`, enabled: true });
    await registry.reorder(['c', 'a', 'b']);
    expect(registry.entries().map((e) => e.id)).toEqual(['c', 'a', 'b']);
    expect(readManifest().entries.map((e: { id: string }) => e.id)).toEqual(['c', 'a', 'b']);
  });

  it('reorder 未列出的 id 按原相对序追加尾部', async () => {
    const { registry } = makeRegistry();
    for (const id of ['a', 'b', 'c', 'd']) await registry.mount({ id, specifier: `mem:${id}`, enabled: true });
    await registry.reorder(['d', 'b']);
    expect(registry.entries().map((e) => e.id)).toEqual(['d', 'b', 'a', 'c']);
  });

  it('reorder 未知 id 抛 PLUGIN_NOT_FOUND', async () => {
    const { registry } = makeRegistry();
    await registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await expect(registry.reorder(['nope'])).rejects.toThrow(/不存在/);
  });
});

describe('PersistentPluginRegistry：失败隔离', () => {
  it('loadPlugin 抛错时记 loadError，其余条目仍 ACTIVE（D10）', async () => {
    const { registry, host } = makeRegistry();
    await registry.mount({ id: 'good', specifier: 'mem:good', enabled: true });
    // mount 显式操作允许抛给调用方，但条目与 loadError 要留下
    await expect(registry.mount({ id: 'bad', specifier: 'mem:boom', enabled: true })).rejects.toThrow(/boom/);

    const diag = registry.diagnose();
    expect(diag.entries.find((e) => e.id === 'good')?.state).toBe('ACTIVE');
    expect(diag.entries.find((e) => e.id === 'bad')?.loadError?.message).toMatch(/boom/);
    expect(registry.fiberOf('good')?.state).toBe('ACTIVE');
    void host;
  });

  it('restore 遇加载失败时吞掉错误继续挂载其余', async () => {
    // 预置清单：bad 在前，good 在后
    writeFileSync(
      file,
      JSON.stringify({
        schemaVersion: 1,
        entries: [
          { id: 'bad', specifier: 'mem:boom', enabled: true },
          { id: 'good', specifier: 'mem:good', enabled: true },
        ],
      }),
      'utf8',
    );
    const { registry, host } = makeRegistry();
    await expect(registry.restore()).resolves.toBeUndefined();
    await host.settle();
    const diag = registry.diagnose();
    expect(diag.entries.find((e) => e.id === 'bad')?.loadError).toBeDefined();
    expect(diag.entries.find((e) => e.id === 'good')?.state).toBe('ACTIVE');
  });

  it('落盘失败时内存照常更新、persistError 有值、操作不抛（D4）', async () => {
    const { registry } = makeRegistry(undefined, { failWrite: true });
    await expect(registry.mount({ id: 'a', specifier: 'mem:a', enabled: true })).resolves.toBeDefined();
    expect(registry.entries()).toHaveLength(1);
    expect(registry.diagnose().persistError?.message).toBeTruthy();
  });
});

describe('PersistentPluginRegistry：还原与卸载', () => {
  it('新实例 restore() 还原清单并挂回 enabled 插件', async () => {
    const first = makeRegistry();
    await first.registry.mount({ id: 'a', specifier: 'mem:a', enabled: true });
    await first.registry.mount({ id: 'b', specifier: 'mem:b', enabled: true });
    await first.registry.disable('b');

    // 新实例（模拟重启）：同一 file，全新 host/context
    const second = makeRegistry();
    await second.registry.restore();
    await second.host.settle();
    expect(second.registry.entries().map((e) => e.id)).toEqual(['a', 'b']);
    expect(second.registry.fiberOf('a')?.state).toBe('ACTIVE');
    expect(second.registry.fiberOf('b')).toBeUndefined(); // b 已停用
  });

  it('restore 幂等：重复调用不重复挂载', async () => {
    writeFileSync(
      file,
      JSON.stringify({ schemaVersion: 1, entries: [{ id: 'a', specifier: 'mem:a', enabled: true }] }),
      'utf8',
    );
    const { registry, host } = makeRegistry();
    await registry.restore();
    await registry.restore();
    await host.settle();
    expect(host.settle).toBeDefined();
    expect(registry.diagnose().core.fibers.filter((f) => f.state === 'ACTIVE').length).toBe(1);
  });

  it('dispose 逆序卸载且幂等', async () => {
    const order: string[] = [];
    const { registry } = makeRegistry(order);
```

```ts
import { describe, expect, it } from 'vitest';
import { readFileSync, readdirSync, existsSync, lstatSync } from 'node:fs';
import { dirname, join, relative, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

const HERE = dirname(fileURLToPath(import.meta.url));
const MAIN_ROOT = resolve(HERE, '..');
const REPO_ROOT = resolve(MAIN_ROOT, '..');
const SRC_DIR = join(MAIN_ROOT, 'src');

function collectTsFiles(dir: string): string[] {
  const acc: string[] = [];
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const full = join(dir, entry.name);
    if (entry.isDirectory()) acc.push(...collectTsFiles(full));
    else if (entry.isFile() && entry.name.endsWith('.ts')) acc.push(full);
  }
  return acc;
}

/** 提取一行里的模块说明符（同 core boundary 的简化版） */
function specifiersOf(text: string): string[] {
  const specs: string[] = [];
  const fromRe = /\b(?:import|export)\b[^;'"]*?\bfrom\s*['"]([^'"]+)['"]/g;
  let m: RegExpExecArray | null;
  while ((m = fromRe.exec(text)) !== null) specs.push(m[1]);
  const sideRe = /^\s*import\s*['"]([^'"]+)['"]/gm;
  while ((m = sideRe.exec(text)) !== null) specs.push(m[1]);
  return specs;
}

describe('boundary：main 的依赖边界', () => {
  const files = collectTsFiles(SRC_DIR);

  it('src 下有源文件（防止断言空转）', () => {
    expect(files.length).toBeGreaterThan(0);
  });

  it('说明符只允许 ./ ../ node: 与 @loop-agent/core', () => {
    const violations: string[] = [];
    for (const file of files) {
      for (const spec of specifiersOf(readFileSync(file, 'utf8'))) {
        const allowed =
          spec.startsWith('./') ||
          spec.startsWith('../') ||
          spec.startsWith('node:') ||
          spec === '@loop-agent/core';
        if (!allowed) violations.push(`${relative(REPO_ROOT, file)}: ${spec}`);
      }
    }
    expect(violations).toEqual([]);
  });

  it('零 import 主工程 src/（零反向依赖）', () => {
    const violations: string[] = [];
    for (const file of files) {
      const text = readFileSync(file, 'utf8');
      for (const spec of specifiersOf(text)) {
        const resolved = spec.startsWith('.') ? resolve(dirname(file), spec) : '';
        // 相对路径解析结果不得落在 main/ 之外
        if (resolved && !resolved.startsWith(MAIN_ROOT)) {
          violations.push(`${relative(REPO_ROOT, file)}: ${spec} → ${resolved}`);
        }
      }
      // 显式禁止跨包引用主工程
      if (/from\s+['"][^'"]*\bsrc\//.test(text)) {
        violations.push(`${relative(REPO_ROOT, file)}: 引用了主工程 src/`);
      }
    }
    expect(violations).toEqual([]);
  });

  it('package.json 的 dependencies 只有 @loop-agent/core', () => {
    const pkg = JSON.parse(readFileSync(join(MAIN_ROOT, 'package.json'), 'utf8'));
    expect(Object.keys(pkg.dependencies ?? {})).toEqual(['@loop-agent/core']);
  });

  it('tsup 配置了 external: @loop-agent/core（D11 防双副本）', () => {
    const text = readFileSync(join(MAIN_ROOT, 'tsup.config.ts'), 'utf8');
    expect(text).toMatch(/external/);
    expect(text).toMatch(/@loop-agent\/core/);
  });

  it('node_modules/@loop-agent/core 是链接（单副本）', () => {
    const linked = join(REPO_ROOT, 'node_modules', '@loop-agent', 'core');
    expect(existsSync(linked)).toBe(true);
    expect(lstatSync(linked).isSymbolicLink() || lstatSync(linked).isDirectory()).toBe(true);
    // Windows Junction 在 lstat 里表现为 symlink；再兜底断言 main/node_modules 不存在
    expect(existsSync(join(MAIN_ROOT, 'node_modules'))).toBe(false);
  });
});
```
