# 任务 01 人工验证指南（壳骨架与进程编排）

> 面向：需要亲手确认桌面端能出窗口、能对话的验证者。
> 原则：**不干扰既有 3000 端口服务**；**不写真实用户数据**；验证完可完整回收。
> 代码依据：`desktop/src/*.ts`，产物 `desktop/dist/main.cjs`。

## 0. 前置检查

```powershell
cd D:\trae_workspace\loop-agent-command

# 三件必需产物
Test-Path dist-sea\loop-agent.exe                     # 应 True（后端）
Test-Path desktop\dist\main.cjs                       # 应 True（壳），否则 cd desktop; npm run build
Test-Path desktop\node_modules\electron\dist\electron.exe  # 应 True，否则见文末环境备注
```

> 你的 3000 端口服务（`node ... src/index.ts --serve`，pid 42148）**全程不用停**。
> 壳会探测到 3000 被占，自动顺延到 3001。

## 1. 隔离启动（推荐做法）

壳与后端共用 `LOOP_AGENT_HOME` 作为数据目录（`desktop/src/config.ts` 已对齐后端
`loopAgentHome()` 的取值顺序）。**必须隔离**，否则壳拉的 SEA 后端会与你正在跑的
开发期服务写同一份 `~/.loop-agent/sessions`，可能互相覆盖。

```powershell
# 1) 建隔离数据目录，并把真实配置复制进去
$env:LOOP_AGENT_HOME = "D:\trae_workspace\loop-agent-command\temp\manual-home"
New-Item -ItemType Directory -Force $env:LOOP_AGENT_HOME | Out-Null
Copy-Item "$env:USERPROFILE\.loop-agent\config.json" (Join-Path $env:LOOP_AGENT_HOME 'config.json')

# 2) 在当前 PowerShell 会话里启动壳（环境变量才能传给子进程）
cd D:\trae_workspace\loop-agent-command\desktop
npm start
```

**必须用同一个 PowerShell 窗口**执行上面两步：`$env:LOOP_AGENT_HOME` 只在当前会话有效，
换窗口会丢，壳就退回读真实配置。

复制 `config.json` 的目的是带上模型 `apiKey`——否则新目录没有模型，能出窗口但发消息会失败。

## 2. P0 主链路：出窗口 + 对话 + SSE

| # | 操作 | 期望 |
|---|---|---|
| 1 | 观察启动 | 约 1 秒内出窗口（无白屏闪烁，`shown:false` + `ready-to-show` 保证） |
| 2 | 看窗口标题 | `loop-agent 控制台` |
| 3 | 看地址栏所在端口 | 实际是 **3001**（3000 被你占用），证明顺延生效 |
| 4 | 输入框发一句「你好，回一句话」 | 回复**逐字/逐块冒出**（流式），不是长时间空等后整段出现 |
| 5 | 切换一次会话再切回 | 内容正常，无报错弹窗 |

第 4 步是唯一能验证 SSE 的环节，必须真发一条消息，不能只看页面渲染。

## 3. P1：退出清理

| # | 操作 | 期望 |
|---|---|---|
| 6 | 直接关窗口 | 窗口消失后，后端进程也随之退出 |

```powershell
# 关窗口后立刻查：应为 False
Get-Process loop-agent -ErrorAction SilentlyContinue
# 端口应无人监听
(Get-NetTCPConnection -LocalPort 3001 -State Listen -ErrorAction SilentlyContinue | Measure-Object).Count
```

> 本任务关窗是**强杀**（`backend-process.ts` 的 `child.kill()`），不是优雅停机。
> 只要进程确实没了就算通过；优雅停机是任务 02 的验收项。

## 4. 错误分支：单测已覆盖，人工构造代价高

这四项**不建议现在手工构造**，原因是要么得临时改名仓库文件、要么得精确卡竞态：

| 验收项 | 为什么暂缓 |
|---|---|
| 「未找到后端程序」 | 开发期有两级兜底（`dist-sea/loop-agent.exe` → `src/index.ts`），要同时改名两个文件才能触发，误操作会把仓库弄脏。**放到任务 04 打包后测**：删 `resources/loop-agent-core.exe` 即可稳定复现。 |
| 「后端启动即失败」+ 日志尾部 | 壳不向透传额外配置，很难让 SEA 后端稳定启动即崩。同上，推迟到打包后构造。 |
| 端口竞态重试 | 需在探测完成到 spawn 之间的毫秒级窗口抢占端口，人工几乎无法复现，**已由单测覆盖**（`desktop-health.test.ts` / `desktop-port.test.ts`）。 |
| 端口全部被占用 | 可人工构造，见下。 |

### 可选：端口耗尽（能测，但会占用 21 个端口）

```powershell
# 占住 3000-3020
$servers = 3000..3020 | ForEach-Object {
  $l = [System.Net.Sockets.TcpListener]::new([System.Net.IPAddress]::Loopback, $_)
  $l.Start(); $l
}
# 另开一个窗口（同样先设 LOOP_AGENT_HOME）启动壳 → 应弹「端口全部被占用」并列出 3000…3020
# 测完释放：
$servers | ForEach-Object { $_.Stop() }
```

## 5. 回收（务必执行）

```powershell
# 关窗口后确认无残留；有的话按 PID 精确清理，不要按名字批量杀
Get-Process loop-agent -ErrorAction SilentlyContinue | Select-Object Id, Path
# 清隔离数据
Remove-Item -Recurse -Force D:\trae_workspace\loop-agent-command\temp\manual-home -ErrorAction SilentlyContinue
# 清掉当前会话的环境变量
Remove-Item Env:\LOOP_AGENT_HOME -ErrorAction SilentlyContinue
```

## 6. 环境备注

本机 Electron 二进制从 GitHub 直连下载会中断，`install.js` 也可能静默不解压。若
`electron.exe` 缺失：

```powershell
cd desktop
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
npm install
# 仍缺 electron.exe 时：手动把 ELECTRON_CACHE 里已下好的 zip 解压到
# desktop\node_modules\electron\dist，并写入 path.txt（内容仅 "electron.exe"）
```

存在且已内嵌 WebUI、5 个桌面测试文件共 31 个用例通过、全量回归 201 文件 / 2605 用例通过。
