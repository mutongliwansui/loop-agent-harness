## 一、任务目标需求

### 1.1 背景（痛点）

`MemoryView.vue` 把「自动晋升」压成一行只读 mono 文本：

```
自动晋升 [每 24h] ⟳ 上次 2026-10-26 20:53 · 晋升 0 条 / 跳过 0 条 · 已整理至 2026-10-25 · 下次 2026-10-27 20:53
```

四个问题：①「每 24h」答不了「几点跑」；②无编辑入口（只能去「配置」页通用配置树改，且改完要重启）；③失败只能翻服务端日志；④「已整理至」是 UTC 日期口径却与本地时间混排。

### 1.2 任务目标

按原型把记忆页重排为 **4 区**：`A 自动晋升（就地可编辑）` + `B 最近触发记录` + `C 分层状态` + `D Curated / Episodic / Gate / 检索`。

1. 卡片 A：`每天 HH:mm` / `每周 X HH:mm` 两个图形档位 + `自定义 cron` 输入，输入即预览未来触发时刻（防抖调 `GET /memory/dream/preview`），保存即生效（`PUT /memory/dream/schedule`）。
2. 非法 cron：红框 + 行内中文错误 + 保存禁用；**右侧排期保持不变**并提示「表达式非法，排期保持不变」。
3. 卡片 B：最近触发记录表（时间 / 来源 / 结果 / 窗口 / 晋升·跳过·错误 / 耗时），空态文案 + 「清空记录」。
4. 运行中态：卡片状态条转绿 + 转圈 + 「正在晋升」。

### 1.3 设计约束

- **前端不实现 cron 解析**：错误与 next 全部来自后端单点实现，避免双实现漂移。
- 样式复用 `style.css` 既有令牌（`--ok/--warn/--danger/--muted/--line-soft/--radius-card/--shadow-card`），**零新增色值**。
- 亮暗双主题、900px 断点单列降级、无横向溢出。
- 代码注释中文。

## 三、任务详细设计

### 3.1 `webui/src/utils/cron-ui.ts`

```ts
export type CronMode = 'daily' | 'weekly' | 'custom';
export function hhmmToCron(hhmm: string): string;      // '03:00' → '0 3 * * *'
export function weeklyToCron(dow: number, hhmm: string): string;  // (1,'09:00') → '0 9 * * 1'
export function cronToMode(cron: string): { mode: CronMode; hhmm: string; dow: number };
export function humanizeDelta(fromMs: number, toIso?: string): string;  // '还有 4 小时 47 分'
export function fmtLocal(iso?: string): string;        // 'YYYY-MM-DD HH:mm'
```

### 3.2 `DreamScheduleCard.vue`

- props：`dreaming: DreamStatus`（含 cron/describe/nextRunAt/nextRunTimes/misfireGraceMin/timezoneOffsetMin/enabled/scheduleEnabled/running）
- emits：`saved`（保存成功后父组件刷新）
- 状态：`mode / hhmm / dow / cronText / previewError / saving / openAdvanced`
- 预览：`watch([mode, hhmm, dow, cronText])` → 300ms 防抖 → `GET /memory/dream/preview?cron=` → 更新 `preview.next`；非法时**不改动**当前排期展示，仅置 `previewError` 并禁用保存。
- 保存：`PUT /memory/dream/schedule` `{enabled, cron, misfireGraceMin}` → 成功 toast + `emit('saved')`。
- 开关：卡片头部 toggle → 同上 PUT `{enabled}`。
- 布局：`grid-template-columns: minmax(0,1fr) minmax(0,1fr)`，900px 以下单列（原型 `.dgrid`）。

### 3.3 `DreamHistoryList.vue`

- props：`runs: DreamRunRecord[]`、`loading: boolean`
- emits：`clear`
- 表格列：时间 / 来源 / 结果 / 窗口 / 晋升·跳过·错误 / 耗时。
- 结果徽标判定（按方案 §11.4 缺陷 1 修正）：`ok` → 成功（绿）；`!ok && promoted > 0` → 部分失败（黄）；`!ok && promoted === 0` → 失败（红）；`skippedBecause` → 跳过（灰）；`skippedBecause==='missed'` → 错过（黄）。
- 空态：「暂无触发记录——定时触发或手动「立即梳理」后，这里会列出结果。」

### 3.4 `MemoryView.vue` 重排

```
页面头：记忆 [已启用]                        ✦ 立即梳理   ⟳ 刷新
DreamScheduleCard（卡片 A）
DreamHistoryList（卡片 B）
分层状态卡片（卡片 C）
Curated / Episodic / Gate / 检索（卡片 D–G）
```
