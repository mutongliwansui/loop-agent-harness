## 一、任务目标需求

### 1.1 背景

`chart-box.ts` 抽共享容器时保留了 mermaid 时期的**功能直出**外观：把 `＋ / － / 100% / ⛶ / </>` 一组字符按钮直接裸露在标题栏上，左侧挂一枚等宽字体的 `echarts` / `mermaid` 徽标。功能齐备，但视觉上像 PDF 阅读器的缩放条，与 Markdown 正文的排版质感脱节。原型诊断出 5 条症状：

| # | 症状 | 现状取值 |
| --- | --- | --- |
| 1 | 标题栏底色与外框对比过强 | `.mmd-bar` 底色 `--bg`，压过卡片边框 |
| 2 | 分隔线偏重 | `border-bottom: 1px solid var(--line)` |
| 3 | 控件形状与语义不对应 | 字符 `＋/－/⛶` 字形大小不一、基线不齐，`100%` 与按钮混排 |
| 4 | 左侧标识像调试遗留 | 等宽小写 `echarts` / `mermaid`，是渲染器名而非用户语言 |
| 5 | 无悬停层次 | 卡片无 hover 反馈，控件 hover 只变底色不描边 |

### 1.3 任务目标

1. 按原型落地**卡片式外框**：图标 + 中文类型名 + 副标题的标题栏、图标式工具组（悬停出名称）、可点击复位的缩放读数、柔和描边与 hover 抬升。
2. 保留全部既有交互语义：缩放 0.2×–5×、按钮 1.25×、滚轮 1.15×、视口中心锚定、拖拽平移、全屏、`remeasure()`、`onResize`、源码/预览切换不重建实例。
3. 类名统一 `.chart-*` 前缀（mermaid 与 echarts 共用），`chart-box.ts` 与两个调用方同步改。
4. 副标题从**真实数据**推导（echarts 读 `series[].type`、mermaid 读源码首关键字），推导不到就不渲染该节点。
5. 令牌化：颜色/圆角/阴影全部走 CSS 变量，亮暗三套主题一致。

### 1.4 设计约束

- 不改缩放/平移/全屏/切换算法，只改「模板 + 样式 + 标识推导」。
- 零新增依赖；不引入 UI 框架或图标库（图标为内联 SVG）。
- 旧类名 `.mermaid-block` 保留为 `.chart-block` 别名一版：旧缓存页（旧 HTML + 新 CSS）仍能拿到外框，只降级为「内部无样式」，不白屏。
- 无障碍：所有图标按钮带 `aria-label`，源码开关带 `aria-pressed`，焦点可见 `:focus-visible` 描边。
- 源码态必须能切回：缩放/适应宽度/全屏置灰，`src` 开关恒可用（否则无控件可退回）。

## 二、方案与决策点

| # | 决策点 | 结论 | 理由 / 否决项 |
| --- | --- | --- | --- |
| D1 | 类名前缀 | 全部 `.chart-*`（`.chart-block` / `.chart-bar` / `.chart-kind` / `.chart-tools` / `.chart-view` / `.chart-stage` / `.chart-hint` / `.chart-source` / `.chart-err`） | 容器已由 mermaid 专用变成 mermaid + echarts 共用，`.mmd-*` 名不副实；否决「两套类名并存」——双份维护、样式必漂移 |
| D2 | 旧类名兼容 | `.mermaid-block` 作为 `.chart-block` 别名保留**一版**；`pre.mermaid-err` / `pre.echarts-err` 并入 `pre.chart-err` | dist 资源带内容散列、`index.html` 不缓存，旧模板只会短暂共存；留别名可避免旧缓存页裸奔 |
| D3 | 左侧标识 | 图标 + 中文类型名（图表 / 图示）+ 副标题；副标题无值时不渲染节点 | 渲染器名（echarts/mermaid）是开发者语言；原型方案 A 的卡片头 |
| D4 | 副标题来源 | **真实数据推导**：echarts 读 `series[].type`（去重、最多 3 种、未知类型回落英文名）；mermaid 读源码首个关键字 | 否决「写死按 kind 出固定文案」：同一 kind 下有柱状/饼图等多种形态，固定文案等于没有信息量 |
| D5 | 推导逻辑归属 | 新建纯函数模块 [chart-labels.ts](file:///D:/trae_workspace/loop-agent-command/webui/src/chart-labels.ts)（`seriesLabel` / `diagramLabel`），两个渲染器 import | 无 jsdom 环境下 DOM 逻辑不可测；纯函数可进 vitest，且避免两处重复维护关键字映射 |
| D6 | 控件形态 | 字符 → 内联 SVG（14×14，`stroke: currentColor`），`100%` 独立成 `.zoom-val` 可点复位 | 字符字形大小/基线不可控；读数兼作「复位」按钮，比第 5 个图标更省位 |
| D7 | 平移提示选择器 | 原型 `.chart-view.pan-able ~ .chart-hint` → **改为** `.chart-view.pan-able > .chart-hint` | `.chart-hint` 是 `.chart-view` 的**子节点**，兄弟选择器恒不命中（原型 bug，照抄则提示永不出现） |
| D8 | 源码面板高度 | 原型 `max-height: 420px` → **改为** `60vh`（与预览态 `.chart-view` 同高） | 两态等高，切换不跳高；否决固定 420px——长图预览态可达 60vh，切到源码会突然变矮 |
| D9 | 令牌归属 | 图表容器令牌写入 [style.css](file:///D:/trae_workspace/loop-agent-command/webui/src/style.css) 三套主题（亮 / 跟随系统暗 / 强制暗） | 其他视图后续可复用；否决写死在 mermaid.css——换主题会漏 |
