## 一、背景与目标

`--serve` 已提供 46 个 REST 端点（会话 5 + 健康 1 + 命令资源化 40），但使用门槛仍是 curl/脚本。本需求在 API 之上提供浏览器 Web UI：聊天 + 运维管理台，**全部复用既有端点，不新增业务面**（唯一例外：对话内上传所需的 raw 二进制上传端点，见 D7）。

用户已确认的选型：**Vue 3 构建链**（方案 B）、**同端口同进程托管**、**聊天 + 全量管理台**、**轻量 token 门**（localStorage + Bearer）、**本机为主兼顾局域网**。

### 检索结论（2026-10-17）

| 结论 | 来源 |
|---|---|
| `EventSource` 仅支持 GET 且**无法自定义 header**，`Authorization: Bearer` 不可行；token 场景需 fetch + ReadableStream 手动解析 SSE | [web-developpeur.com: SSE Streaming with Fetch API](https://www.web-developpeur.com/en/blog/sse-fetch-readable-stream-api-key)、[掘金: fetch 实现 SSE](https://juejin.cn/post/7512775145702834195) |
| `vite build` 产物为可静态部署的纯静态文件；SPA history 路由需服务端 fallback（未命中回 index.html）或改用 hash 路由规避 | [Vite 官方文档: 构建生产版本](https://cn.vitejs.dev/guide/build)、[Vue Router: History modes](https://router.vuejs.org/guide/essentials/history-mode) |

## 二、总体架构

```
浏览器 SPA（Vue 3 + Vite 构建 → webui/dist/）
    │  fetch / XHR（Authorization: Bearer <token>，localStorage 记忆）
    │  SSE：fetch + ReadableStream 逐帧解析（D5，EventSource 无法带 header）
    ▼
node:http server（--serve，同端口同进程）
    ├─ ① API 路由优先匹配（46 端点，行为零变化）
    └─ ② 未命中 → 静态托管 webui/dist（D3）
         ├─ GET /            → index.html
         ├─ /assets/*        → 带 hash 的 js/css（immutable 缓存）
         └─ 其余未命中       → SPA fallback index.html（hash 路由下仅兜底）
```

- 运行时**零新依赖**：托管仍手写 `node:http`（~100 行静态中间件）；Vue/Vite 只是前端工程的构建期依赖（webui/ 独立 package.json）。
- API 46 端点行为零变化；新增的只有「静态文件回落」这一条路径。

## 三、详细设计

### 3.1 前端工程（webui/）

```
webui/
  package.json          # 独立 devDeps：vue / vite / @vitejs/plugin-vue / vue-router / marked / dompurify
  vite.config.ts        # base: './'（相对路径，托管在任意子路径均可用）
  index.html
  src/
    main.ts             # 入口：router + pinia-lite（自建轻量 store）+ token 门
    api/client.ts       # 统一 fetch 封装：Bearer 注入 / 401 拦截 / 错误归一
    api/sse.ts          # fetch + ReadableStream 解析 SSE 帧（D5）
    views/
      ChatView.vue      # 会话侧栏（list/create/delete）+ 消息流（SSE 渲染）+ 停止按钮 + 对话内上传（📎 面板：文件选择框 + contextNote chip）
      ConfigView.vue    # 配置树（masked）+ 单键读写删 + scope 切换
      ModelsView.vue    # profile 登记簿 + 激活切换 + 连通性测试
      ToolsView.vue     # 内置工具列表 + 启用/禁用 + reload（MCP 提供的工具不在此展示）
      McpView.vue       # 服务器列表 + 各服务器提供的工具明细 + 登记/测试/删除 + reload
      SkillsView.vue    # 技能列表 + 安装（源路径）+ 卸载 + reload
      MemoryView.vue    # 分层状态 + 检索 + gate 阈值 + dream/init
      DoctorView.vue    # 逐项体检卡片
    components/         # 复用件：状态徽标 / JSON 查看器 / 确认按钮（动词即确认语义）/ UploadPanel（对话内上传：文件选择框 + chip）
```

- 路由用 **hash 模式**（`#/chat`、`#/models`…，D4）：刷新/直达零服务端耦合。
- 状态管理不引 pinia：视图间仅共享 token 与极少全局态，用 `reactive()` 模块级单例足够。

### 3.2 静态托管（src/api/static.ts）

```typescript
export function serveStatic(root: string): (req, res, next) => Promise<boolean>
// 返回 true 表示已响应（命中静态文件 / index.html fallback）；
// false 表示放行（API 路由先于静态中间件执行，未命中 API 才进入）
```

- 顺序：`handleRequest` 中**先 matchRoute（46 端点）→ 未命中且 GET → serveStatic**。
- 解析：`path.normalize` + 前缀校验（解出的绝对路径必须仍在 root 内，防穿越，复用 skill remove 先例思路）。
- MIME 内置表：html/js/css/mjs/json/svg/png/jpg/ico/woff2/txt/map。
- 缓存：`/assets/*`（Vite hash 文件名）→ `Cache-Control: public, max-age=31536000, immutable`；index.html → `no-cache`。
- 托管根可配（`api.webRoot`，默认 `webui/dist`）；目录不存在 → 静态层静默跳过（纯 API 模式不受影响）。

### 3.3 鉴权 token 门（D6）

- 静态文件（HTML/JS/CSS）**不做鉴权**：内容为公共前端代码，无敏感数据。
- 所有 API 调用统一注入 `Authorization: Bearer`（token 存 localStorage）；`client.ts` 收到 401 → 清 token → 弹输入框。
- 首次进入：GET /health（带 Bearer）探测 —— 200 即 token 有效 / 无需 token；401/403 → 弹输入框。
- 本机无 token 模式：全程零感，无任何登录交互。

### 3.4 聊天视图（核心链路）

- 会话侧栏：GET /sessions 列表 → 新建（POST /sessions）→ 删除（DELETE /sessions/:id，409 busy 提示）。
- 消息发送：POST /sessions/:id/messages（SSE）→ `sse.ts` 逐帧解析 → 按 `event` 字段分发渲染：
  - `llm_stream` 追加正文；`tool_start/tool_end` 渲染工具调用折叠块；`final` 定稿；`done` 收尾；`error/warning` 告警条；`fatal` 终止提示。
  - `AbortController` 提供「停止生成」。
- **对话内上传**（归位到聊天，不设独立菜单；浏览器标准交互 = 文件选择框，见 D7）：
  - 输入区 📎 按钮 → 面板「选择文件…」→ `<input type="file" multiple>` 系统文件选择框 → 逐文件 `POST /uploads/raw?sessionId=`（请求体 = 文件字节，`X-File-Name` 头传文件名；超 100MB → 413）→ 成功后以 chip 展示（文件名 + 大小）；
  - chip 的 contextNote（`[文件上传] 文件名 / 上传路径 / 大小`，复用既有 buildContextNote 格式）自动拼入下一条消息文本；chip ✕ = 仅移除不再注入（服务器文件保留）；
  - 面板下方为已上传管理列表（GET /uploads：文件名 / 大小 / contextNote 复制）+「清空全部」（DELETE /uploads 整目录清理，动词即确认）；API 无单文件删除端点，chip 移除为纯前端语义。
  - 后端配套（唯一新增端点）：`src/upload/manager.ts` 新增 `writeUpload(sessionKey, fileName, bytes)`——复用既有时间戳命名 / 同名冲突 / 大小上限逻辑；`handlers/uploads.ts` 新增 raw handler + 路由（会话不存在 404 / 文件名缺失 400 / 超限 413）；端点总数 46 → 47。
- 非流式开关（`stream: false`）作为设置项。

### 3.5 管理台视图（7 组）

每视图 = 列表 + 行内操作 + 表单，全部映射既有端点（与 http-api.md 端点表一一对应）：

| 视图 | 端点映射要点 |
|---|---|

| Doctor | GET /doctor 卡片流（ok 绿 / missing 黄 / blocker 红） |

### 3.6 错误边界

| 场景 | 行为 |
|---|---|
| API 返回 `{error:{code,message}}` | client.ts 归一 → 顶部 toast（409/404/400 均显示后端 message） |
| SSE 中断/网络断 | 消息流标记「连接中断」，保留已收帧 |
| 401 | 清 token → 弹输入框（见 3.3） |
| webui/dist 不存在 | 启动日志提示「WebUI 未构建：cd webui && npm install && npm run build」，API 正常服务 |
| 大 JSON（/memory/curated 全文） | 折叠查看器，默认收起 |

## 四、关键设计决策（D1–D9，待确认）

| # | 决策 | 取舍与理由 |
|---|---|---|
| D1 | **webui/ 独立 Vite 工程**（Vue 3 + TS） | 主包零运行时新依赖，前端 devDeps 不污染后端；否决：主包统一依赖（装包变慢、后端被迫耦合前端版本） |
| D2 | **构建产物 webui/dist 提交进 git** | clone 即用（--serve 起服务即有 UI，无需 node 环境）；否决：不提交（用户需先装前端依赖构建，违背开箱即用）<br>**⚠ 已变更（2026-10-25，用户决定）：`webui/dist` 不入库**，`.gitignore` 已忽略 `/webui/dist/`；clone 后需执行一次 `npm run build:webui`。本条保留为历史决策记录，现行为下表描述为准 |
| D3 | **node:http 手写静态中间件**，API 路由优先 | ~100 行、防穿越可控；否决：serve-static 等 npm 包（违反零运行时依赖惯例） |
| D4 | **hash 路由**（#/chat 等） | 刷新/直达零服务端协同，fallback 仅兜底；否决：history 路由（需服务端 fallback 精确配合，收益仅 URL 美观） |
| D5 | **fetch + ReadableStream 解析 SSE** | EventSource 无法带 Authorization header（检索已证）；否决：EventSource + token 拼 URL query（token 进日志/历史记录，泄露面大） |
| D6 | **静态页不鉴权，API 全 Bearer**，401 弹 token 门 | HTML/JS 无敏感数据；否决：静态层也校验 token（需把 token 传给 <script>/<img> 请求，复杂度陡增无安全增益） |
| D7 | **对话内上传 = 浏览器文件选择框 + 新增 `POST /uploads/raw` 二进制端点**（每文件一请求：body = 文件字节 + `X-File-Name` 头；服务器复用既有落盘/命名/100MB 上限逻辑；不引 multipart 解析） | 浏览器安全限制拿不到文件本地完整路径，「输入服务器路径」反常规交互，用户评审明确否决；既有 POST /uploads（路径模式）保留给 CLI/脚本场景；否决：multipart（零依赖手写 boundary 解析复杂易错）/ 路径输入框（已否决） |
| D8 | **中文单语 + 跟随系统深浅色** | 与 CLI 输出语言一致；否决：双语 i18n（演进项） |
| D9 | **marked + DOMPurify 渲染 Markdown** | 模型输出需安全渲染（防 XSS）；属 webui devDeps（构建期），不违反运行时零依赖；否决：纯文本渲染（聊天体验倒退） |
