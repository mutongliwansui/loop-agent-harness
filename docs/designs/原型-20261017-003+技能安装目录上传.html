原型说明：安装技能从「手填服务端本地路径」改为「浏览器目录选择框 + 整目录上传」。
  • 点「📁 选择技能目录」可 真实选择本机目录（webkitdirectory，Chrome/Edge/Firefox 支持，含子目录全部文件）；或点「注入示例」快速看各状态
  • 选中后自动校验根目录含 SKILL.md（缺失 → 错误条 + 禁用安装），并尝试从 frontmatter 解析 name 预览
  • 同名冲突未勾选覆盖 → 模拟 409 toast；勾选覆盖 → 覆盖安装；成功后列表实时可见
  • 上传为一次性 JSON（base64）提交 POST /skills/upload，后端落临时目录后复用现有安装校验链（见下方契约）

接口契约（设计稿）新增 POST /skills/upload
POST /skills/upload   Content-Type: application/json
{
  "scope": "workspace" | "global",
  "overwrite": false,
  "rootName": "my-skill",                                  // 所选目录名（即安装目录名）
  "files": [ { "path": "SKILL.md", "content": "<base64>" },   // path 为目录内相对路径（含 / 子目录）
             { "path": "scripts/run.py", "content": "..." } ]
}
