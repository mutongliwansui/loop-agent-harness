loop-agent-command

README.md · 8.4 KB · UTF-8

基于 OpenAI 协议 Function Calling 的 TypeScript ReAct Agent CLI，附带 HTTP API 与独立 Vue3 WebUI。

npm install
npm run build
loop-agent --serve      # 启动 WebUI

在终端标签中可以直接运行构建、测试与 git 命令，工作目录默认落在当前会话的工作空间。
