6待确认决策点（D1–D6）

  1. D1 展开区限高：min(42vh, 320px) 内部滚动（推荐）／按任务数自适应不限高（否，仍是原问题）。
  2. D2 已结束组默认收起：默认收起 + 组头计数（推荐）／默认展开（列表变长，本次主要痛点）／干脆不展示已结束任务。
  3. D3 收起态 chips 上限：保持 3 个 + +N 移出裁切容器（推荐，改动最小）／降为 2 个（+N 数字更大但信息更少）。
  4. D4 任务 ID 呈现：缩略 + 复制图标（推荐）／保留全宽平铺（现状，挤标题）／完全移除（丢可复制能力）。
  5. D5 全部收敛后：维持现状整块隐藏（推荐，避免常驻占位）／保留「已结束」入口若干秒（需额外状态机）。
  6. D6 一键停止全部：本期不做（推荐，危险操作需二次确认）／做（超本次范围）。
