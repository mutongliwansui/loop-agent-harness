关键设计决策（D1–D10，待确认）

D1 预览呈现：复用对话页内 FilesView 面板（点 chip → 面板自动展开预览），窄屏为抽屉态。否决：独立浮层预览组件（渲染链路重复维护）
D2 跨组件通道：ToolCard emit('open-path') → ChatView → FilesView defineExpose({ openPath }) 组件 ref 直调，不引全局总线、不进 URL。
D3 路径分类：tool-meta 新增 PATH_ARGS 显式映射 + classifyPathArg 纯函数（file/dir/url/data/missing/outside 六态），单测覆盖。否决：按扩展名启发式猜目录
D4 chip 落点：仅参数表行值与组卡子行；卡片副标题（brief）保持纯文本（非目标）。
D5 uploads 端点：新增 GET /uploads/view?path=&disp=file|raw（file 与 /fs/file 同构、raw 直显字节）；resolveInWs(uploadsRoot) + realpath 双重校验、只读。否决：给 /fs/* 加 uploads 分支（权限面混淆）
D6 uploads 识别：前端以 /.loop-agent/uploads/ 子串嗅探分流 + 后端强校验兜底；可见范围为 uploads 根内全部会话（历史回放需要），误判最多 403 不越权。
D7 不可点分类：url/data/outside/missing 渲染纯文本 + title 注明原因，不做「可点但必失败」噪音交互。
D8 文件不存在：不预检 stat，直接走 openFile 既有错误链路 + toast，避免双请求竞态。
D9 相对路径基准：相对工作空间根（与工具语义一致）；反斜杠归一为 /；ws 内绝对路径透传（/fs/* 本就兼容）。
D10 令牌与依赖：零新依赖、零新令牌；chip 复用 --line-strong 虚线 + --hover + 线性 SVG（stroke 1.2~1.4）。
