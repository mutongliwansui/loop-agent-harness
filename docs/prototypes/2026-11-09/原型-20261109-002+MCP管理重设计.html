现状问题

McpView 旧版

旧版把「运行状态 + 配置 + 工具元信息 + 登记表单」四件事平铺在一页：宽表格承担状态扫读，写入范围与删除范围混用一个下拉，元信息卡正文 5 行小字。重设计的目标是状态优先、一卡一 server、操作分层、配置可下钻。

1
表格列被长命令挤压

command / URL 最长，名称与状态被推到视觉边缘；连接状态只是一个文字徽标，扫读成本高。

2
「写入 scope」语义不清且被复用

页头一个 scope 下拉同时决定登记与删除范围。全局 server 在默认工作空间范围下删除会返回 deleted:false，旧版仍提示成功。

3
工具名中文化占一整张卡片

正文五行小字说明翻译优先级与失败项，真正的服务器状态被挤到页面下方；失败详情无处展开。

4
测试、明细、删除等权平铺

行内三个按钮 + 行内展开原始 JSON，缺少「主要动作 / 次要动作 / 危险动作」分层。

5
无搜索、筛选、排序

server 变多后只能逐行肉眼查找；state、lastError、nextRetryAt 已由接口返回，但页面只显示 已连接/未连接。

6
空态与失败态缺少引导

空库只有一行文字；连接失败不展示原因和重试倒计时；登记 502 半态只有 toast，关了窗就不知道配置已落盘。

设计决策

D1–D9 · 待确认后落地

除 D9 需要列表接口补一个字段外，其余决策都不改后端。标注「推荐」的项为原型默认方案；「待确认」的项落地前需要你点头。

D1
卡片流替代表格推荐

一卡一 server：名称、来源范围、连接状态、连接目标、工具数与测试结果处于同一视区。长 command / URL 单行省略并支持一键复制，不再挤压状态列；≥980px 两列，窄屏单列。连接目标来自 GET /config 的 tools.mcpServers。

D2
状态成为首要信息推荐

state 四态映射 pill；失败卡左侧色条 + lastError + nextRetryAt 倒计时；统计条汇总已登记 / 已连接 / 异常 / 工具总数。异常只统计 failed，连接中与待连接不制造额外焦虑。

D3
测试结果留在卡片推荐

点击「测试」后 chip 依次显示 测试中 → 通过 / 失败，并带延迟与工具数（对应接口 ok / latencyMs / tools / error）。结果保留到下一次刷新或重载；toast 只做补充，不作为唯一反馈。

D4
登记改为模态 + 条件字段推荐

transport 分段切换：stdio 显示命令 / 参数 / 环境变量，SSE 与 HTTP 显示 URL / 请求头；范围用两张 scope 卡（默认工作空间）；「登记后立即连接」可关。409 与 502 都在模态内解释，不靠 toast 承载关键信息。

D5
移除确认带范围选择推荐

确认框内单独选 scope，默认等于卡片徽标所示范围。范围不匹配时展示 deleted:false 的原因并保持弹窗；只有删除成功才移除卡片并 toast。彻底移除旧版「页级 scope 同时决定登记与删除」的耦合。

D6
中文化从主卡降级为徽标推荐

主页面只保留工具条右侧的「工具名中文化 已译/总数」徽标，点击弹出说明层；翻译失败项折叠在抽屉的工具区，正文不再占一整张卡抢走状态焦点。

D7
搜索 / 状态筛选 / 排序推荐

搜索匹配名称、command 与 URL 并高亮命中；分段为 全部 / 已连接 / 异常；排序为 状态优先 / 名称 A→Z / 工具数降序；计数常显，空结果给出清空入口。

D8
重载直接执行，不弹二次确认推荐

「重载」是页级幂等操作（POST /mcp/reload），失败不会破坏配置。执行后 toast 汇报成功数与失败名单，并刷新列表；二次确认只留给「移除」这类破坏性动作。

D9
每卡显示来源 scope依赖接口小改待确认

需要 GET /mcp/servers 的每一项增加 scope（workspace / global，取自配置来源）。未提供时卡片隐藏徽标，移除确认默认工作空间并在弹窗内提示「请确认登记范围」。这是本轮唯一建议的接口改动。

接口映射

端点零改动（D9 例外）

每个视觉元素都能对应到现有响应字段；抽屉与卡片不额外造数据。登记失败的 409 / 502、移除的 deleted:false 都在对应位置解释。

端点用途对应展示
GET /mcp/servers列表 + 运行态卡片、统计条、分段筛选、失败倒计时（state / lastError / nextRetryAt / toolCount / transport）
GET /config合并生效配置卡片连接目标、抽屉配置区（tools.mcpServers[name] 的 command / args / url / headers；secret 已遮蔽）
GET /mcp/servers/:name详情 + 工具清单抽屉的连接信息、工具列表、原始 JSON；失败时显示查询错误与重试时间
POST /mcp/servers登记（502 = 半态）登记模态内联 409 / 502；成功后插卡；502 后引导至异常卡并说明配置已落盘
POST /mcp/servers/:name/test主动测试连接卡片测试 chip：测试中 / 通过 / 失败 + 延迟 + 工具数（ok / latencyMs / tools / error）
POST /mcp/reload重载全部连接页级「重载」按钮；toast 汇报 reconnected 与 failed[]，随后刷新列表
DELETE /mcp/servers/:name?scope=按范围移除移除确认框的 scope 选择；deleted:false 时提示范围不匹配，不误报成功
GET /mcp/tool-meta工具名中文化工具条徽标（已译 / 总数）、抽屉工具名与中文参数、抽屉内翻译失败折叠
差异说明：旧版忽略 DELETE 响应的 deleted:false，也只用 toast 承载 502；新版把两者都变成可留存的内联解释。D9 可选：列表项增加 scope 后，来源徽标与移除默认范围即可自动对齐；不增加时按上文降级。
