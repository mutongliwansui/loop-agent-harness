四、状态与视觉规则

running · 呼吸点 + 顶部呼吸线 done · 静态绿点 failed · 红点 + 错误摘要一行 aborted / interrupted · 灰点
元素规则
显示条件存在 running 任务才渲染；全部收敛后自动隐藏（沿用现有逻辑）
收起标题后台子任务 + 计数胶囊 N 运行中；数量为 0 时组件不渲染
任务 chips最多 3 个：#序号 + 实时耗时；溢出显示 +N。单任务且宽度 ≥ 480px 时追加任务短名（≤ 18 字）
聚合耗时max(now - startedAt)，1s 走表；与单个 chip 的耗时同源
展开行标题task 原文，12.5px sans，2 行 clamp，hover 显示完整标题
状态词进行中 / 完成 / 失败 / 已取消 / 已中断（沿用现有 label 映射，颜色仅作用于状态词与点位）
失败摘要error 首个非空行，剥前缀后截 60 字；无 error 时显示「执行失败」
动效顶部 2px 呼吸线 + running 点位 1.5s 脉冲；prefers-reduced-motion 下全部关闭
窄屏 <720px隐藏 chips 与聚合耗时，保留图标 / 标题 / 计数 / chevron；展开列表行标题改为 3 行 clamp

六、不做（本期边界）

  • 不做进度百分比：后端没有「总步数」概念，硬造进度是假信息；用顶部呼吸线表达「仍在跑」即可。
  • 不加取消按钮：取消涉及 API 与 registry，超出「样式重设计」范围。
  • 不改显隐逻辑：仍只在有 running 任务时出现。
  • 不引入新字号层级：标题 12.5 / 正文 12.5 / meta 11，与现有对话卡片一致。
