三、调用链时序

主 Agent run()
　└─ LLM 返回 tool_call: delegate(task="...")
　└─ delegate.execute(args, ctx)
　　　└─ ctx.runSubAgent(task)　// 由主 Agent run() 注入
　　　　　└─ new ReActAgent(configLoader)
　　　　　└─ attachMemory(共享 kit)　// 共享 L2/L3，独立 L1
　　　　　└─ sub.run(task, { excludeTools:['delegate'], signal })
　　　　　│　└─ 子 Agent 独立 ReAct 循环（工具调用不暴露给主对话）
　　　　　└─ return { answer, iterations }
　　　└─ sub.dispose()
　└─ observation = answer　// 回写主对话，主 Agent 继续推理

四、防递归

子 Agent 的 excludeTools: ['delegate'] 在两处生效：

  1. 工具列表过滤：传给 LLM 的 tools 不含 delegate，LLM 看不到该工具。
  2. 执行阶段拦截：若 LLM 幻觉仍调用 delegate，返回「工具 delegate 在此上下文中不可用」，不递归执行。
