| 20260930-002 | 命令输入自动补全 | 输入命令时没有自动补全提示，例如输入 `/con` 应联想出 `/config`，用户按 Tab 键后可自动补全为 `/config` | 2026-09-30 | 是 | 2026-09-30 |
| 20261010-001 | 视觉模型对接（图片理解） | 当前 Agent 仅支持纯文本对话，无法理解图片；建议对接支持视觉的多模态模型（OpenAI 协议 image_url 消息格式）：用户可直接粘贴/引用本地图片路径或 URL，Agent 将图片（本地转 base64 data URL）以多模态 content 发送给模型，实现看图问答、截图分析、UI 还原等能力；可配套 `vision.model` 独立配置与 `/vision` 相关命令 | 2026-10-10 | 是 | 2026-10-10 |
| 20261011-001 | 初次启动引导（初始化检测与配置向导） | 全局配置（~/.loop-agent/config.json）、workspace 配置（.loop-agent/.agent-config.json）及 skills 等目录目前需用户手动创建，首次使用门槛高；建议增加两个功能：1）Agent 启动时自动检测必备目录与配置是否已创建和配置，齐备则直接进入对话界面，否则进入初次加载引导界面；2）引导界面分步完成初始化——核心的主模型配置（model.baseUrl/apiKey/name）由用户输入（可校验连通性），其余配置项（vision、session、memory、tools 等）与 skills 等目录按默认值自动生成 | 2026-10-11 | 是 | 2026-10-11 |
| 20261011-002 | 多模型接入与切换 | 当前模型的配置接入只支持单个模型（model.baseUrl/apiKey/name 单组配置），要更换模型必须重新走一遍配置流程，之前的配置会被覆盖，切换成本高；建议支持接入多个模型配置（如 models 列表，每项含 baseUrl/apiKey/name 及可选别名），并保留当前激活项指向；配套增加模型切换命令（如 /model 列出已接入模型、交互选择或按别名切换 /model use <别名>），以及新增接入、移除模型配置的子命令，切换仅改变激活项不动各模型已有配置 | 2026-10-11 | 是 | 2026-10-12 |
| 20261012-001 | 文件上传（/upload 会话隔离上传目录） | 当前让 Agent 处理本地文件只能手敲绝对路径，长路径/含空格路径易错，且临时文件混入工作空间污染 git 工作区；建议新增 /upload 命令：把本地文件复制到全局上传目录（~/.loop-agent/uploads/）并按会话隔离存放（uploads/{sessionId}/），上传完成后将路径注入会话上下文供 Agent 下一轮直接用 fileRead/commandRun/视觉工具处理；支持拖拽（跨终端格式归一）、无参弹出系统文件选择框（Windows/macOS/Linux 探测）、多选、list 与 clean 子命令，/session delete 连带清理对应上传目录 | 2026-10-12 | 是 | 2026-10-12 |
| 20261015-001 | MCP Streamable HTTP 传输支持 | 当前 MCP 接入只支持 stdio 与 sse 两种传输（`src/tools/mcp/client.ts` 的 `MCPServerConfig` 仅 `StdioConfig \| SSEConfig`，`/mcp add` 交互与 `/mcp list` 详情同样只认 stdio/sse），无法接入仅提供 Streamable HTTP 端点的远程 MCP Server；而 MCP 规范自 2025-03-26 起已用 Streamable HTTP 取代 HTTP+SSE，并在 2026-07-28 规范中将 HTTP+SSE 标记为 Deprecated（SEP-2596），继续只支持 sse 会逐步失去生态兼容性。建议新增 streamableHttp 传输：配置项 `{ type: 'streamableHttp', url, headers? }`（`headers` 用于 Bearer Token / API Key 等认证头），底层复用 SDK 已内置的 `StreamableHTTPClientTransport`（`@modelcontextprotocol/sdk` 1.30.0 已提供，零新增依赖）；同步支持 `/mcp add` 交互选择与 `/mcp list` 详情展示，并保留 sse 传输以兼容存量配置 | 2026-10-15 | 是 | 2026-10-15 |
