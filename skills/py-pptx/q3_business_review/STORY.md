# STORY.md — 2026 年第三季度业务汇报

## 叙事金字塔（5 问）

| 问题 | 答案 |
|---|---|
| 听众是谁？ | 公司管理层（CEO / CFO / 各业务线负责人），季度经营会 |
| 听完要做什么？ | **决策**：批准 Q4 增长策略与资源投入 |
| 页数预算 | 10 页（约 10 分钟） |
| 场合与调性 | 季度经营会 → **商务咨询风格**（Action Title 结论式标题 / Navy 权威感 / 结构图优先 / 数据 + Source 可信） |
| 内容边界 | 必须讲：Q3 业绩、关键亮点、市场洞察、Q4 增长策略、落地路线；不讲：财务审计细节、未公开客户信息、非核心业务线细节 |

## 叙事结构

```
P1  cover      封面 · hero/peak          「2026 年第三季度业务汇报」
P2  toc        目录 · transition         「业绩回顾 → 市场洞察 → 增长策略 → 落地行动」四段式
P3  content    执行摘要 · supporting/valley   Context / Complication / Resolution 三栏
P4  content    Q3 业绩 · supporting/valley   营收 + 毛利率数据图表（主图 ≥50% B 区）
P5  content    Q3 亮点 · hero/peak       三大 KPI 锚点（营收增速 / 留存 / 人效）
P6  section    章节过渡 · transition     「02 · 市场洞察」巨字编号
P7  content    竞争格局 · supporting/valley  2×2 矩阵结构图 + 右侧洞察
P8  content    Q4 增长策略 · supporting/valley  三大增长引擎战略结构图（≥70% C 区）
P9  content    Q4 落地路线 · supporting/valley  三阶段路线图（甘特式结构图）
P10 ending     行动号召 · hero/peak      「批准 Q4 增长预算，锁定全年目标」
```

## 角色与节奏检查

- Hero 页：P1 / P5 / P10 = 3 页 = 30%（配额 20%-30% ✓）；peak 间隔：P1→P5 隔 3 页、P5→P10 隔 4 页，均 ≥2 页 ✓
- 结尾页为 peak，与 P9（valley）形成「谷→峰」收束 ✓
- 页面类型顺序：cover → toc → content × 3 → section → content × 3 → ending ✓
